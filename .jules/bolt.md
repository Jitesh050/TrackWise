## 2024-05-26 - [PassengerDashboard Optimization]
**Learning:** In React functional components, creating new collections like Maps `new Map()` from static data on every render creates unnecessary O(N) allocation and garbage collection. When moving these into `useMemo`, remember that if the source data is a static global import, it should either be placed entirely outside the component or the `useMemo` dependency array should be correctly managed (e.g. empty `[]` for static imports) to avoid linter warnings/errors.
**Action:** Always check the scope of the data source when hoisting to `useMemo`. If it's a global import, it often belongs outside the component body completely. Additionally, always revert unintended lockfile changes (like `bun.lockb` permissions) caused by local package manager commands.
