## 2024-05-18 - [Optimization] Hoist static map & consolidate multi-pass unmemoized loops
**Learning:** Found an anti-pattern in `PassengerDashboard.tsx` where a static map (`byCode`) of stations is re-created on every render. Furthermore, there are multiple unmemoized iterative passes over the same `tickets` array (`activeBookings`, `nextJourney` sorting, `milesTraveled` map rebuilding).
**Action:** Always look to hoist static data transformations that group or filter related entities out of interval/render loops and into module-level Maps to reduce computational overhead. Additionally, consolidate multiple O(N) array transformations over the same array into a single `.reduce()` or loop inside a `useMemo` hook, and replace O(N log N) sorting with O(N) minimum-finding where applicable.
