## 2024-07-30 - [Optimize FAQ search filtering]\n**Learning:** Discovered an anti-pattern in `src/pages/HelpCenter.tsx` where a static data array (`faqs`) and unmemoized derived data (`filteredFaqs`) were placed inside the component, leading to O(N * M) redundant calculations on every render.\n**Action:** Hoisted the static `faqs` array outside the component and wrapped the filter calculation in a `useMemo` hook, precomputing the `searchQuery.toLowerCase()` evaluation outside the loop to optimize performance and prevent redundant re-renders.
