## 2024-05-10 - Consolidate iterative O(N) filtering in TrainManagement.tsx
**Learning:** In components with multiple stat counters based on array filtering (like calculating length of `Active` and `Maintenance` trains, total capacity, and occupancy), developers often write multiple chained `array.filter(..).length` or `array.reduce(..)` expressions inside the component render body. These result in several redundant O(N) loops. Also, if the data is a static mock array, creating it inside the component causes redundant allocations on every render.
**Action:** Extract static mock arrays outside the component. Consolidate multiple iterative passes over the same array into a single `.reduce()` or `for` loop outside the component if data is static, or inside a `useMemo` block if data is dynamic, reducing complexity from O(K*N) to O(N). Also, always hoist `.toLowerCase()` out of the `.filter()` loop.
