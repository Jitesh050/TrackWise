## 2024-03-22 - Passenger Dashboard O(N) Array Consolidation
**Learning:** React functional components in this codebase frequently derive multiple UI statistics (active counts, aggregations, sorted next-items) via chained array methods (`.map`, `.filter`, `.reduce`, `.sort`) on the same raw prop data. This causes severe unmemoized O(N) map recreations and O(N log N) sorting blocks on every render for pages displaying arrays.
**Action:** When deriving multiple scalar metrics or simple extremes from an array in a component, consolidate the independent chained loops into a single, combined O(N) iterative pass utilizing primitive variables wrapped inside a `useMemo` block. Replace expensive functional sorting (`.sort()`) with single-pass O(N) min/max primitive tracking when only the first or next item is needed.
