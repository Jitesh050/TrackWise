## 2024-05-19 - Seat Selection Map Randomization & Memoization
**Learning:** In React components that generate mock or randomized data (like a seat map using `Math.random()` for availability) inside the render loop, failing to memoize the generation causes the mock data to regenerate on every state update (e.g. clicking a seat). This not only causes performance overhead (re-allocating arrays and dicts on every click) but also introduces a severe functional bug where UI state flickers/changes unexpectedly.
**Action:** Always wrap static or randomized mock layout generation in a `useMemo` with an empty dependency array `[]` when within a component. Ensure any dynamic state (like `isSelected`) that depends on component state is removed from the memoized mock generation and instead computed during the JSX render loop (e.g. `isSelected={selectedSeats.includes(seat.id)}`).
