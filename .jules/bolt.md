## 2024-08-11 - Train Status Filtering Optimization
**Learning:** React components (like `TrainStatus.tsx`) often use an anti-pattern of chaining multiple `Array.prototype.filter` and `Array.prototype.map` operations during render to derive filtered state. This creates unnecessary intermediate arrays and re-evaluates string operations (like `toLowerCase()`) inside the loop, turning an O(N) operation into a more computationally expensive O(N * C) operation where C is the number of filters/maps.
**Action:** Consolidate multiple list transformations (like mapping trains to a presentation format and then filtering by search query and active tab) into a single `.reduce()` pass wrapped in a `useMemo` hook. Hoist invariant calculations (like `searchQuery.toLowerCase()`) outside the loop to optimize the render cycle.
