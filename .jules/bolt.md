## 2024-04-02 - Optimize Multiple Array Filter passes by consolidating into Single Reduce pass
**Learning:** Found a common performance anti-pattern across multiple pages (e.g. `TicketManagement`, `PassengerDashboard`, `UserManagement`, `TrainManagement`) where multiple O(N) `array.filter(condition).length` calls are used sequentially in the render loop to calculate aggregated statistics. This redundant iteration causes N traversals per render. Furthermore, iterating over a list inside a filter block while continuously running `toLowerCase()` on a search term causes O(N) string operations per render that could easily be hoisted.
**Action:** When working on lists that require multiple aggregated stats, consolidate them into a single pass using `array.reduce()` wrapped in `useMemo`. When filtering a list with a text query, ensure that transformations like `.toLowerCase()` applied to the search query are hoisted outside the filter block.
