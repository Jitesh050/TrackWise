## 2025-01-20 - Array Iteration Consolidation and Static Data Extraction
**Learning:** In highly trafficked React components doing computations over large arrays, multiple chained array methods (`.filter().length`, `.map()`, `.reduce()`, `.sort()`) can be significant performance bottlenecks, causing redundant object allocations and multiple array traversals (often resulting in O(N log N) logic or worse). Repeated recalculations inside functional components without memoization makes this even slower. Furthermore, recalculating complex, static mappings (like converting an array of stations into a Map structure by ID) within the render body causes unnecessary memory re-allocations on every render.
**Action:** When optimizing such components, extract static configurations and data structures (like lookup maps) outside the component definition. Additionally, consolidate scattered array traversals into a single block wrapped in `useMemo`, utilizing a single loop to calculate multiple derived state pieces concurrently. Replace sorting logic with minimum/maximum trackers when finding extremities (like the next future date), reducing time complexity from O(N log N) to O(N).
