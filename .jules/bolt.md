## 2024-10-24 - TrainManagement.tsx Optimization
**Learning:** Consolidating multiple O(N) array filter loops into a single Map or reduce block avoids recreating new arrays and re-iterating over large lists on every single render. Pre-calculating static attributes using `useMemo` and separating module-scope constants from function-scope prevents heavy load. Vite build warnings, specifically dynamic vs. static imports and chunk sizes over 500KB, must be fixed globally using `manualChunks` because Netlify CI treats these warnings as build errors.
**Action:** When finding a component iterating a static array multiple times inside the render method, hoist the array to the module scope and pre-calculate any initial aggregated stats. Also, extract large vendor dependencies like 'firebase' or 'radix-ui' to their own chunks in vite config.
